# Stock Price Analyzer

### Java-Based Stock Management and Analysis System

## Project Overview
Stock Price Analyzer is a Java-based application developed to manage and analyze manually entered stock price records. It provides a graphical user interface to add, search, sort and analyze stock prices.

## Technologies Used
- Java
- Java Swing
- Data Structures and Algorithms
- File Handling and Serialization

## Data Structures Implemented
- **ArrayList:** Stores stock records.
- **Stack:** Supports undo operations.
- **Queue:** Maintains the five most recent records.

## Algorithms Implemented
- Linear Search
- Binary Search
- Merge Sort
- Maximum, Minimum and Average Price Calculation

## Key Features
- Add and manage stock records
- Search for company records
- Sort stock prices
- Undo the last added record
- Display five recent records
- Calculate stock price statistics
- Visualize stock price trends using charts
- Save records using file serialization

## Project Files
The repository contains the Java source code, project report and presentation.

## How to Run
1. Install the Java Development Kit (JDK).
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Compile the Java files:
   `javac *.java`
5. Run the application:
   `java Main`
